## 0. 三方案共用的 Fluent 基础

无论选择哪套方案，以下基础全部一致，保证“和 WinUI 靠齐”的底线：

### 0.1 设计令牌

| 令牌 | 值 | 说明 |
|------|-----|------|
| 字体 | `Segoe UI Variable`（降级 `Segoe UI`）+ `Microsoft YaHei UI` | 时间数字用 Display 变体；**tabular figures**（等宽数字，WPF 中 `Typography.NumeralAlignment="Tabular"`）保证秒跳不抖动 |
| 圆角 | 窗口 8px / 卡片与控件 4px / 时钟条 8px | Win11 标准 |
| 字号 | Caption 12 · Body 14 · Body Strong 14/600 · Subtitle 20 · Title 28 | |
| 间距 | 4px 网格 | |
| 材质 | 窗口 **Mica**、浮层 / 时钟条 **Acrylic** | Win11 22H2+ 用 `DwmSetWindowAttribute(DWMWA_SYSTEMBACKDROP_TYPE)`；Win10 自动降级为纯色近似 |
| 颜色 | 深浅色、强调色**全部跟随系统** | 不再硬编码白色主题；`DWMWA_USE_IMMERSIVE_DARK_MODE` 深色标题栏 |
| 图标 | `Segoe Fluent Icons`（Win10 降级 MDL2 Assets） | |
| 动画 | 150–250ms 快速曲线（控件 hover / 浮层出现 / 主题切换） | |

### 0.2 共同的交互决策（三方案都做）

1. **设置即时生效**：移除现有「应用 / 确定 / 取消」三按钮，所有改动即改即存（Win11 设置模式）。
2. **城市行内编辑**：列表行内直接改名 / 换时区，替换现有 DataGrid 双击编辑。
3. **Win11 风格上下文菜单**：时钟条右键菜单重绘（Acrylic、圆角、图标）。
4. **深浅色自动跟随系统**，保留 6 套主题预设作为手动覆盖（浅色 / 深色 / 高对比 / 雾蓝 / 暖砂 / 玻璃）。
5. **配置文件向后兼容**：`settings.json` 现有字段全部保留，新增字段带默认值。

### 0.3 实现路线（共用）

- **不迁移框架**：保持 .NET 8 + WPF。迁移 WinUI 3 会让托盘图标、无边框置顶工具窗口、多显示器定位这些现有强项全部重做且平台限制更多，收益只有控件库——不值得。
- 用一个 `Styles/Fluent.xaml` 资源字典重绘全部控件观感；窗口材质用 Win32 DWM API 接入（三行 P/Invoke，失败静默降级）。
- 现有功能（拖拽、边缘吸附、托盘、多显示器、开机自启、单实例）**全部保留不动**。

## 方案 A · 原生延伸 —— “像系统自带的功能”

**定位**：时钟条是任务栏的自然延伸，设置窗口 1:1 复刻 Windows 11 设置应用。安全、耐看、零学习成本，是“最 WinUI”的一套。

### A1 时钟条

- **形态**：单行 Acrylic 细长条，高 40px（与任务栏视觉呼应），圆角 8，距任务栏上沿 4–6px。
- **排版**：每城市 = 城市名（12px，60% 透明度）+ 时间（14px Display SemiBold，tabular）；城市间 1px 竖线分隔（14% 透明度）。
- **秒数弱化**：秒 52% 透明度，主时间不跳。
- **hover**：单个城市出现 6px 圆角高亮块；同时浮现 tooltip 显示该城市完整日期 + 星期。
- **右键**：Win11 风格上下文菜单（图标 + 分隔线 + 圆角）。

### A2 设置窗口

- **结构**：720×560，Mica 背景；左侧 NavigationView（搜索框 + 「时钟 / 个性化 / 行为 / 关于」，选中态 3px 强调色侧条）；右侧内容区大标题 + 卡片分组。
- **卡片**：Win11 设置式圆角卡片，每行 = 图标 + 标题 + 灰色副标题描述 + 右侧控件（ToggleSwitch / ComboBox），行间 1px 分隔线。
- **城市卡**：城市行（名称 + 时区副标题）+ 行尾 ⋮ 菜单（上移 / 下移 / 删除）；卡底部「＋ 添加城市」强调色文字按钮。
- **个性化页**：颜色（背景 / 文字 / 分隔符，行内色块 + 取色器）、字体、字号、条高、圆角、透明度、位置对齐、显示器，全部行式控件。
- **关于页**：版本、配置路径（可打开）、GitHub 链接、`--reset` 说明。

### A3 优缺点与成本

- ✅ 与系统集成度最高，长期最耐看；深浅色 / 强调色全自动，维护心智最低。
- ⚠️ 个性表达最弱；时钟条信息只有时间。
- 成本：**高**（全量控件重绘 + Mica 接入，估 2–3 天）。

## 方案 B · 快捷浮层 —— “小组件 + 快速设置”

**定位**：把高频操作从设置窗口里搬出来。时钟条升级为小组件行，设置改为「条上弹出的快捷浮层 + 低频项 Pivot 大窗」双层结构。

### B1 时钟条

- **形态**：Acrylic 小组件行，每城市一块 tile：上行城市名（11px，60%）+ **时差徽章**（`本地` / `−7h` / `+1h`，强调色小胶囊），下行大号时间（18–19px Display SemiBold）。圆角 10，悬浮阴影更明显，整体有“卡片”存在感。
- **两档尺寸**：紧凑（单行 32px，隐藏徽章与秒）/ 舒展（如上，高约 56px）。
- **hover**：tile 高亮；条右端浮现 ⚙ 按钮；hover 城市 tile 浮现详情气泡（完整日期、星期、时差）。
- **点击 tile** → 弹出该城市详情卡（日期 / 星期 / 时差，为将来日出日落留位）；**双击**（保留现有习惯）→ 打开大窗外观页。

### B2 设置（双层）

- **快捷浮层**（360px，从条下方弹出、带指向箭头、点击外部关闭）：
  - 顶部三枚快捷开关磁贴：显示秒 / 始终置顶 / 开机自启（Win11 快速设置样式，开 = 强调色）；
  - 中部城市列表：⠿ 手柄**拖拽排序**、行内改名删除；
  - 底部「打开全部设置 →」。
- **大窗**：顶部 Pivot 页签（时钟 / 外观 / 行为 / 关于）替代左导航，内容同样卡片分组；承载尺寸档位、徽章开关、颜色、字体等低频项。

### B3 优缺点与成本

- ✅ 高频操作路径最短；时差徽章 / 详情卡信息扩展性最强；最现代。
- ⚠️ 视觉存在感最强、占宽最大；浮层 + 大窗双层结构实现细节最多（弹层定位、关闭逻辑、动画）。
- 成本：**中高**（新浮层组件 + 时钟条重构，估 2–3 天）。

## 方案 C · 极简墨字 —— “排版即界面”

**定位**：去掉一切装饰，时钟条像“印在桌面上”的一行字；设置收窄为单列流。实现最轻，气质独特。

### C1 时钟条

- **形态**：**无背景、无边框、无分隔线**，纯文字排印；城市间距 28–32px 分组；hover 才浮现 4% 背景 + 6px 圆角（拖拽暗示）。
- **排印**：城市名 12px Light 300（62% 透明度）+ 时间 20–23px Display Light，tabular 数字；秒为 12px 小号上标（42% 透明度），弱到几乎不抖动感知。
- **文字色自适应**：默认跟随系统深浅色；可手动锁深 / 锁浅；提供「跟随壁纸明暗」可选项（实现上取壁纸平均亮度，属增强项可后置）。
- **极简模式（可选）**：只显示 `HH:mm`，hover 自动展开城市名与秒。

### C2 设置窗口

- **结构**：560×600 单列窗口：大标题「设置」+ 搜索框，从上到下依次「主题 / 排版 / 城市」三个分组，无左导航无页签。
- **主题**：**6 张色卡网格**（每张卡内是一个迷你时钟条预览），点选即换，选中态 2px 强调色描边 + 对勾。
- **排版**：字体 / 字号（滑杆）/ 秒数样式（完整 / 上标 / 隐藏，三段式分段控件）。
- **城市**：⠿ 拖拽排序 + 行内删除 + 「＋ 添加」。

### C3 优缺点与成本

- ✅ 最轻最不打扰，常驻桌面最耐看；实现成本最低；Fluent 排印气质。
- ⚠️ 可读性依赖壁纸对比度（需自适应文字色兜底）；信息扩展性弱（放不下徽章 / 详情）；「极简」反而意味着个性化空间小。
- 成本：**低**（排版与材质为主，估 1–2 天）。
