WorldClockBar · UI Redesign Proposal

向 Windows 11 / WinUI 靠齐的三套方案

三套方案共享同一套 Fluent 设计基础：跟随系统深浅色与强调色、Mica / Acrylic 材质、Segoe UI Variable 字体、4px 网格圆角与细腻动画。差异集中在两处——时钟条的形态与设置窗口的信息架构。以下为高保真静态预览（浏览器直接渲染），逐条规格见同目录 design-proposals.md。本页不含任何项目代码改动。

Mica / Acrylic 材质Segoe UI Variable跟随系统深浅色系统强调色设置即时生效Win10 自动降级
方案 A

原生延伸 —— 像系统自带的功能

时钟条是任务栏的自然延伸（Acrylic 细长条 + 竖线分隔）；设置窗口 1:1 复刻 Windows 11 设置应用：NavigationView 左导航 + 圆角卡片分组 + 行式控件。

实现成本 高
Acrylic 单行条Win11 设置式卡片NavigationView⋮ 行菜单即时生效

取舍

个性表达最弱，时钟条只有时间信息；Win11 设置式全量控件重绘 + Mica 接入，改动面最大。
方案 B

快捷浮层 —— 小组件 + 快速设置

时钟条升级为“小组件行”：每城市一块 tile（大号时间 + 时差徽章）；设置改为从时钟条弹出的 360px 快捷浮层（Win11 快速设置风格），高频开关一键直达，低频项收进 Pivot 大窗。

实现成本 中高
小组件 Tile时差 / 日期徽章快捷浮层拖拽排序Pivot 大窗紧凑 / 舒展两档

取舍

视觉存在感强、占宽最大（城市多时需滚动或收起）；浮层 + 大窗双层结构，交互状态与实现细节最多。
方案 C

极简墨字 —— 排版即界面

时钟条去掉一切装饰：无背景、无分隔线，只留优雅的字体排印（细字重 + tabular 数字 + 秒数上标），像“印在桌面上”。设置窗口收窄为 520px 单列流，主题用色卡点选。

实现成本 低
无边框纯排版细字重 + tabular 数字秒数上标主题色卡单列设置流文字色自适应

三方案对比

方案 A · 原生延伸方案 B · 快捷浮层方案 C · 极简墨字
一句话定位像系统自带的功能，最大公约数的安全选择高频操作最快，信息可扩展的小组件排版即界面，最轻最不打扰
时钟条形态Acrylic 细长单行条，竖线分隔，与任务栏同高呼应小组件 Tile 行：大号时间 + 时差徽章 + 悬浮阴影无边框纯文字，细字重 + 秒数上标，靠间距分组
设置架构NavigationView 左导航 + Win11 卡片行（像系统设置）360px 快捷浮层 + Pivot 大窗双层520px 单列流：搜索 + 主题色卡 + 排版 + 城市
信息扩展性低（仅时间）高（时差徽章、城市详情卡、可加日出日落）低（排版紧凑）
交互亮点行内编辑 + ⋮ 菜单；Win11 上下文菜单一键快捷开关；拖拽排序；tile 详情气泡主题色卡即点即换；壁纸自适应文字色
实现成本高（全量控件重绘 + Mica，约 2~3 天）中高（新浮层组件 + 条重构，约 2~3 天）低（排版与材质为主，约 1~2 天）
适合谁想要“装了就像没装、系统该有的样子”跨时区沟通多、频繁看时间换算的重度用户追求桌面美学、讨厌界面元素的轻量用户

实现说明（三方案共用）：不迁移框架，保持 .NET 8 + WPF，通过 DwmSetWindowAttribute（DWMWA_SYSTEMBACKDROP_TYPE / DWMWA_USE_IMMERSIVE_DARK_MODE / DWMWA_WINDOW_CORNER_PREFERENCE）接入 Mica / Acrylic / 深色标题栏与圆角窗口；Win10 自动降级为纯色材质。所有控件（ToggleSwitch、ComboBox、Slider、上下文菜单、标题栏）用 WPF 样式重绘为 Fluent 观感，时间数字启用 tabular figures 防抖动。现有功能（拖拽、边缘吸附、托盘、多显示器、自启）全部保留。
