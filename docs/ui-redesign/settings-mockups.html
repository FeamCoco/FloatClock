WorldClockBar · 设置窗口深色重设计

设置窗口 · 三个深色方案

针对「卡片发黑、与背景反差过大」的问题出了三个方向：方案一去掉卡片盒子、用分区线代替，最极简； 方案二保留 Win11 卡片结构、把层次翻转为「卡片比背景微亮」，最稳； 方案三暖炭底色 + 品牌橙贯穿，最有个性。内容均为 1:1 实际尺寸的「时钟」页。

为什么现在的卡片发黑：当前卡片底色是 #12FFFFFF（7% 白色半透明）叠在窗口背板上——Mica 正常时只是微微提亮，一旦背板没接管，半透明区域就直接压在黑底上渲染成近黑色块。三个方案全部改用不透明色阶，任何背板状态下观感一致。
方案一 · 一体无界去掉卡片盒 方案二 · 雾层微抬升Win11 标准 方案三 · 暖烬品牌暖色 + 品牌橙
方案一

一体无界 · 用分区线代替卡片

整窗只有一层表面，彻底消灭"黑块"：分组之间只留一条 1px 分区线，控件直接浮在窗面上。 视觉噪音最低、最耐看，接近 VS Code / macOS 设置的气质；代价是分组感比卡片弱，依赖间距与线来呼吸。

方案二

雾层微抬升 · 标准双层次

保留现有卡片结构，但把明度关系翻转为正确方向：窗口更深（#1C1C20）、卡片比背景亮一档（#28282D）， 加 8px 圆角和发丝边。层次全靠"卡片微微浮起"表达，不再有黑块压在浅底上的违和感。最接近 Win11 设置应用的原生气质。

方案三

暖烬 · 品牌橙贯穿

把系统给的橙色强调色当作品牌色用：整窗换成带暖调的炭色（#211E1A），卡片微暖、 分区线与控件边都掺一点橙。导航选中、分组标题、开关、链接全部由橙线串起来，辨识度最高—— 一眼能认出"这是 WorldClockBar 的设置"，和时钟条的暖色调也互相呼应。

怎么选

求稳、最像原生 Windows → 方案二。改动可控，只是把明度关系修正 + token 全部换不透明，风险最低。

喜欢极简、讨厌任何"块" → 方案一。界面最安静，但分组辨识靠分区线，习惯卡片式的人需要适应。

想要应用自己的气质、和橙色时钟条成套 → 方案三。个性最强，也最容易在截图里被认出来。

三稿均为静态 HTML 实际尺寸渲染；选定后在浏览器里用 Ctrl++/- 缩放检查细部，也可让我把任意两稿做混合（例如"方案二的卡片 + 方案三的橙色语义"）。
