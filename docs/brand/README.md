## 1. 品牌锚点：「经线 Meridian」

一条经线定义一个时刻。多时区时钟条的本质，就是**同一时刻在不同经线上的读法**。
整条品牌线——色彩、标志、命名——都从这一个概念长出来，不引入无关装饰。

- **中文名**：经线
- **英文名**：Meridian
- **定位**：常驻桌面、不打扰的系统级工具，克制、精密、工具感
- **禁用**：渐变光晕、拟物高光、多余阴影（与"常驻桌面"的定位冲突）

## 3. 标志

三个方向均已产出完整资产，可直接对比后定稿。

| 方向 | 概念 | 大尺寸 | 16px 托盘 | 结论 |
|---|---|---|---|---|
| **A · 子午盘** | 圆环 + 贯穿的竖直经线 | 好 | **好** | **推荐** |
| B · 双环 | 两环相交、明度分层，指"两地同一时刻" | 好 | 糊成一团 | 不推荐，除非另做简化小尺寸变体 |
| C · 仪表弧 | 310° 开口环 + 指针，仪表感最强 | 好 | 尚可 | 备选 |

**为什么推荐 A**：环与经线共用圆心，是"经线"概念最短的几何表达；左右对称，缩到 16px
仍是一个"带竖线的圆"，不会糊。见 `contact-sheet.png` 的逐尺寸对照。

### 尺寸规范

| 场景 | 尺寸 | 边距 | 用哪个文件 |
|---|---|---|---|
| 应用图标 | 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 | 标志占宽 58%（148/256） | `<方向>/app.ico` |
| 应用图标底色 | — | 圆角 = 边长 × 22% | 渐变 `#12A594` → `#0B5F58`，135° |
| 托盘图标 | 16 / 20 / 24 / 32 | 标志占满，笔画加粗 1.5× | `<方向>/tray-*.ico` |

> **小尺寸不是缩放出来的**：`≤32px` 使用独立的加粗几何（描边 20 → 30），
> 直接缩小 256px 版本会让笔画低于 1px 而发虚。`generate-icons.py` 已按此规则分档渲染。

## 4. 托盘图标策略

当前 `TrayIconService` 用的是 `SystemIcons.Application`——Windows 通用默认图标，**与品牌无关**，
这是必须修掉的一处。

建议按系统主题切换，三个变体都已产出：

| 变体 | 色值 | 适用 | 文件 |
|---|---|---|---|
| 白 | `#FFFFFF` | 深色任务栏（系统深色主题） | `tray-white.ico` |
| 品牌青 | `#0F766E` | 浅色任务栏，品牌露出 | `tray-teal.ico` |
| 墨 | `#0A1F1D` | 浅色任务栏，最高对比度 | `tray-ink.ico` |

判定逻辑可直接复用已有的 `ThemeService.IsDarkTheme`。注意任务栏颜色与系统主题并非严格一致
（例如自定义了任务栏配色时），所以「浅色」这一档建议默认用**墨**版——它不依赖品牌色的对比度。

## 5. 时钟条布局

### 5.1 结构变化：从"平铺一行"到"城市成组"

| | 现状 | 重设计 |
|---|---|---|
| 层级 | 城市名 + `HH:mm:ss` 同一行，秒数靠降透明度区分 | 上行城市名（次级）／下行大号时间（主色）+ 小号秒（三级） |
| 分隔 | 每城市间 1px 竖线 | **去掉分隔线**，组间距 26px 留白划分 |
| 本地城市 | 无标识 | 城市名前 6px 品牌青圆点 |
| 时差 | 无 | 城市名行右侧 10px 三级色时差标识 |

### 5.2 规格

| 项 | 值 |
|---|---|
| 条高 | 60px（原 40px；成组后需要两行） |
| 圆角 | 12 |
| 内边距 | 16 |
| 组间距 | 26 |
| 城市名 | 11px / `textSecondary` |
| 时分 | 19px / `Inter SemiBold` / `textPrimary` / **tabular figures** |
| 秒 | 12px / `inter Regular` / `textTertiary`，与时分底对齐 |
| 组内行距 | 2 |
| hover | 该组加 6px 圆角浅底（深色 6% 白 / 浅色 5% 黑），并展开完整日期 + 星期 |
| 材质 | 沿用 Acrylic / Mica，`barBg` 见 §2.4 |

> WPF 中秒数与分时用两条 `TextBlock` 放在同一个横向 `StackPanel` 里（底对齐）即可，
> 比原来的同一条文本靠透明度区分更容易控制层级。

## 6. 设置窗口布局

沿用 Win11 设置范式（左导航 + 圆角卡片），只做两处实质改动：

1. **导航顶部加入品牌身份**：22px 标志 + `WorldClockBar` 文字标，替代原来只有一个搜索框的开头。
   这是窗口与图标同源的地方。
2. **选中态换品牌青**：导航选中项 = 3px 品牌青指示条 + 一层浅底 + 主色文字；
   「＋ 添加城市」等主操作、开关的开启态全部换成品牌色。

其余（卡片分组、即时生效、行内编辑、⋮ 菜单）保持不变——现有实现已经是对的，不必重做。
